# 微信工作流与运行面板

> 关联决策: ADR-0004、ADR-0008

## 概述

用户可以在微信中用自然语言查找、读取、修改或发送已授权目录中的文件，并在本地面板查看需要等待、恢复或外发的操作状态。普通聊天仍是正常对话，不会因为出现“文件”“图片”或“笔记”等字样就自动执行操作。

## 能力

- 可以按文件名或相对位置查找已授权目录及其全部允许访问的子目录中的文件，按文件类型筛选同样适用于子目录。中英文连写、空格、标点、全角字符和大小写差异可作为模糊查询，首次条件过窄没有结果时可以根据原意调整后继续查找。目录未变化时，分批查询保持相同排序，不因大小写混合而重复或漏掉文件。
- 可以搜索已授权文本文件的正文片段；需要更多上下文时会按有限行数读取。单次结果过大可缩小范围重试，整轮文件数量或文字预算耗尽则需新一轮请求。
- 文件处理意外中断后，助理可以在当前对话中再次查询，不必为此重启整个服务；恢复处理不会自动重复刚才失败的修改或发送。是否继续查询由助理根据当前结果决定。
- Concurrent file searches take turns across chats, so a later small search can progress before a large search finishes. Each chat keeps its own results and resource allowance; cancelling one does not cancel another.
- 可以在已保存写入权限的目录中创建文本文件，或在读取并确认内容版本后精确修改现有文本文件；内容冲突时不会覆盖。同一次修改中断后恢复时，会核对已写入结果而非重复修改，不会仅因单行文字较长而恢复失败。重试早先操作时，如果文件之后又被修改，会提示冲突，不会覆盖新内容或把旧结果当作当前版本。
- 创建文件时可以同时建立所需子目录；同时在同一个新目录下创建不同文件不会仅因目录被另一次创建而失败。同时新建同名文件时只允许一份成功，另一份不会覆盖它。
- 可以把已选中的任意普通文件作为文件附件发送到当前微信；发送已有原文件不需要把正文读入对话。
- 本地图片会作为图片消息发送；“最新一张图片”在指定来源中选择修改时间最新的唯一结果，不出现多余的选择步骤。
- 只有一个合理结果时直接继续；有多个合理结果时显示安全文件名供选择，不会擅自发送第一个。
- 候选提示会说明本次可选择一项还是多项；单选提示只提供单项示例，允许多选时可以选择一个、多个或全部。每个选中项分别发送，结果未知的项目不会自动重发。
- 可以先列出图片或文件供选择、选完再发送；展示待选本身不会发送附件。排除部分候选而保留其余时，只发送保留的项目。仅查询名称或数量不会因此进入待选发送。
- 同一微信账户与目标同时只保留一个待选择任务；提出完整的新操作会结束旧待选，旧引用不能再次恢复。同一句话放弃旧操作并提出新任务时，会继续处理新任务；仅放弃旧操作时则取消。
- 在最近已显示的待选提示后，数字、中文序数、候选描述和自然语言取消均可用于回复；候选发生真实变化时会展示当前选项并要求重新确认，新提示发送成功后可按新列表回复序号。提示尚未发送成功、候选已过期或任务再次被替换时，不会把旧序号应用到另一项操作。
- 连续发送的多条独立消息会按发送顺序逐条处理，当前文件操作及收尾结束后才处理下一条，不会被合并成一个问题；正常停止服务时等待已经开始的操作收尾，尚未开始处理的消息在重启后仍保留原顺序。强制结束进程不保证完成收尾。
- 普通回复只发送模型正常完成后的最终答案，不会把思考过程、流式残片或工具旁白发送到微信；只有答案文本但处理仍未结束时会继续等待，随后失败或断连不会被当成成功。允许继续处理的临时错误不会让同一消息重新开始，也不会因此重复发送附件；没有可用最终答案时会明确失败。
- 要求原样引用文字时，原文与文件名中的括号、末尾标点等符号应予保留，不做统一删标点处理；模型回复仍可能出现笔误。
- 文件或图片发送接管后，最终回复只陈述实际运行结果，不会把模型的中间推测或内部组件名称发给用户。
- 文件或图片操作已经开始后，即使最终提示生成失败，也不会改用助理的推测或自动重发附件；无法生成可靠提示时会告知本次暂时无法处理。这条提示不表示之前的附件发送已撤销，可先检查微信中的实际附件。
- 本地“工作流运行”页显示最近运行、需要关注的运行、步骤状态、耗时和外发结果，页面仅供查看。
- 服务重启后仍可恢复尚未完成的待选任务和已持久化运行，不重复执行已经确认成功的外发。

## 边界与不做

- 已知限制：跨页查找后要求发送全部文件，仍可能出现漏选；即使收到“文件已发送”，也不能据此确认全部匹配文件都已发送。需要核对实际收到的文件数量，当前不承诺这一场景稳定完成。

- 维护者可在本机查看近期交互的阶段耗时、工具结果与发送尝试，关联同一待选操作的前后回复。默认保留 7 天，空间不足可能提前清理；本地诊断不再脱敏，可能包含查询词、路径、账户与目标标识及网络地址参数；分享前请先审查。不会主动增加聊天、文件正文或请求头采集，不新增诊断页面。
- 图片及文件批量发送可按选中顺序排查每一项，查看上传或提交阶段的安全失败类别，以及尝试、接受、拒绝、结果未知和未尝试的数量；不会因诊断发现失败而自动重发。
- 本机诊断还可查看主服务和文件处理进程的事件循环、堆内存、垃圾回收与活动资源指标。指标每 30 秒保存，正常关闭时补采；没有发生的事件可能没有对应记录。不自动记录每个底层文件操作，也不能仅凭进程指标判定某次请求的原因。
- 文件处理诊断可区分初始化与请求执行耗时，查看超时、主动关闭和实际退出，并区分触发故障的请求与同一进程中受影响的其他请求。重新启动的文件处理进程与旧进程分别关联，不会把旧进程退出误记为新请求失败；执行耗时包含通信与结果确认，不等于纯文件读写时间。模型处理与本地操作、权限及资源收尾分别计时，不把收尾等待算作模型生成。
- 诊断记录不完整、已清理或尚无结束证据时会说明限制；排查信息不能代替操作结果，也不证明手机已经收到消息。诊断保存缓慢或失败时，允许诊断记录缺失，不要求文件查询等待日志落盘，也不会改变文件权限或自动重发。
- 回复后的本地记录保存失败时，面板保留失败提示，不被后续发送成功或新消息的提示覆盖；不会因此重新执行操作或重发回复。提示保留到本次服务退出，不能保证重启后仍可查看尚未保存的记录及提示。

- 本地文件只能来自已经保存权限的目录；写入包含读取，搜索范围包含已授权的只读和可写目录。读取结果可能进入该账户下当前已启用目标的独立 Codex 微信会话。
- 撤销目录读取权限后，即使文件已经列入待选，也不会继续发送该目录中的原文件；会提示重新配置读取权限。已保存的账户记忆不随文件读取权限撤销而删除。
- 文件不能被执行；当前也不支持删除、移动、改权限、解压或安装。
- 修改现有文本会保留原有权限位，但不保证保留扩展属性、创建时间等其他文件属性。
- 修改中断后，只清理能确认属于同一次修改、且未被改动的临时文件；无法确认归属的残留会保留，不批量清理用户目录。
- 旧版仅启用写入的目录会按读写权限使用；未授权目录和只读目录不会因此获得写权限。
- 二进制文件可以查找和发送，但不能作为文本读取或修改；系统照片图库等受操作系统保护的资源不会被遍历。
- 微信和飞书查询“下载目录最新文件／视频”时默认包含子目录，不会擅自改成只查顶层。大目录会持续分批查找，只有完整扫描后才认定最新文件；达到资源上限、超时或无法读取时会说明限制，不会仅凭局部结果宣称文件不存在、已找齐全部或已确定最新文件。查找失败不会靠原样反复重试来代替完整扫描。不完整查找返回的候选不能直接用于发送。
- File operations retain a 60-second execution allowance per conversation turn. Waiting behind other searches is counted separately, with up to 60 seconds of cumulative waiting per turn; a full queue or exhausted waiting allowance is reported separately from an incomplete search. Total elapsed time can exceed 60 seconds, and other activity on the computer can still affect performance.
- 文件类型筛选支持逐项列出多个类型；不支持的花括号筛选写法不会被当作“没有匹配文件”，需要调整查询条件。
- “已发送，请查收”以渠道接受结果为依据，不承诺手机端一定已经显示；发送结果无法确认时会明确提示检查微信并且不自动重发。
- 运行页不会取消任务、确认未知结果、重放外发或修改权限。
- 本地面板只在经[本机登录](agent-console.md)授权的浏览器里打开。
- 升级前已经列出的旧文件候选可以继续选择；选择时仍需有读取权限且候选尚未过期。旧候选若没有保存当时的内容版本，将发送选择时的文件内容，不能检测自旧搜索以来的内容变更。
- 升级前尚未完成的旧版文件查找会结束，不会擅自恢复或发送文件。系统会向原聊天提示重新提出请求；无法确认原接收人时不改发其他聊天。会话暂不可用时保留通知，通知已被接受或发送结果未知时不自动重发。
