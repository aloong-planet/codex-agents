# 工作流模块权限

> 关联决策: ADR-0010、ADR-0008

## 概述

用户在“本地权限”页按模块和目录决定独立微信助理可以读取或写入哪些本地文件。权限在首次启用或设置阶段保存，运行中的对话不能自行申请、更改或扩大目录范围。

## 能力

- “本地权限”页显示当前可配置模块及其目录范围；笔记目录和本地媒体目录分区显示。
- 每个目录默认勾选读取、关闭写入，保存前只是建议草稿；保存写入权限会同时开启读取，只读不能修改。
- 点击“保存更改”后显示“已配置”和明确反馈；旧页面不会静默覆盖更新后的配置。
- 已保存读取权限后，微信可以查找目录中的文件；正文搜索或有限窗口读取的结果可能进入该账户下当前已启用目标的独立 Codex 微信会话。
- 已保存写入权限后，可以查找、读取、创建文本文件，并在核对文件版本后精确修改已有文本文件。
- 文件执行能力始终禁止，不存在可以开启的执行选项。

## 边界与不做

- 页面只能调整已登记目录的读写权限，不能提交任意路径；新增任意目录的本机选择器尚未开放。
- 保存权限本身不会读取、修改或发送任何文件；新权限只从后续微信操作开始生效。
- 关闭读取时需要同时关闭写入；只关闭写入可以保留只读访问。
- 收窄读取权限后，旧独立微信会话不会继续复用已经撤销的文件访问上下文。
- 文件不能被执行、删除、移动、改权限、解压或安装。
