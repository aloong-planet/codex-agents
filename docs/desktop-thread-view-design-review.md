# Codex Desktop 任务查看设计审查

## 结论

方案可进入实现，但必须把“请求 Desktop 导航”和“原生只读查看成功”分开描述。

## 审查发现与修正

1. **不能由面板传入 thread ID**：否则任意 UI 调用可打开不属于当前微信目标的本机任务。修正为只传账户和目标，由后端从私有映射解析。
2. **不能把打开深链标为接管或只读**：Codex Desktop 没有公开的只读导航参数。按钮与反馈明确标记为实验导航。
3. **不能用 shell 字符串执行**：使用 `execFile` 和固定参数，thread ID 必须通过 UUID 正则。
4. **目标已启用不等于 thread 一定存在**：后端以持久 session 映射为最终门禁，并返回可操作提示。
5. **打开原生页面是本地 UI effect**：MCP tool 仅 app 可见；用户必须在面板点击，不提供模型自动调用入口。
6. **当前 App Server 所有权保持不变**：不 resume、不 unsubscribe、不关闭微信服务，避免因查看破坏微信连续交互。
