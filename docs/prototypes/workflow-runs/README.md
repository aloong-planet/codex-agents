# 工作流运行 UI 原型

目标功能：通用工作流引擎的只读运行观察页。

要回答的问题：采用“运行列表 + 详情双栏”时，用户能否快速识别当前任务、权限预检结果、并行步骤、外部副作用结果和可采取的安全动作。

已选择的结构方向：左侧运行列表，右侧运行详情。视觉沿用现有深色 Tokei 风格。

原型是零后端的设计验证，不代表功能已经实现。页面底部的“演示状态”悬浮条属于演示基建，不进入正式产品。

权限不足是终止结果，不是会话中审批状态。用户只能前往独立设置页修改模块权限，再手动发起新运行。

## 独立诊断页（历史探索，已移出首期范围）

2026-09-09：后续已接受 ADR-0011，首期仅提供本地有界 OTel 记录与只读查询，不新增诊断 Tab，也不采集原始查询。下面保留原型当时的设想，不代表当前实施计划或已批准的隐私扩展。未来若重启界面设计，需重新确认并同步现行 [spec](../../specs/workflow-runs.md)。

此前探索过独立诊断 Tab：以回合而非工作流运行作为列表入口，兼容未创建工作流的工具调用。
单页原型 `prototype-diagnostics.html` 验证左侧回合列表、右侧调用详情以及顶部临时详细采集的层次。
原型尚未获得界面确认，不代表生产页面已上线；正式 spec 的脱敏展示待定项尚未关闭。

- 默认安全摘要；目录、查询和文件只用模拟安全标签。
- 显式开启后，仅新模拟调用可查看原始查询；关闭或到期清除，历史无法回溯恢复。
- 导出按钮只打开模拟安全摘要预览，不生成文件、不落盘。
- 边界：读取拒绝、扫描不完整、无工具调用、空列表、详细值过期。
- 底部悬浮演示控件用于制造模拟状态，不进入产品。
- 15 分钟是待确认的演示期限；实际保留期限、容量、本地身份校验与服务端强制清除尚待设计收口。
- 按项目能力声明，i18n 未启用，该项跳过；本页仅覆盖现行中文深色主题，未验证其他语言与主题。

改动面外发现：现有控制台品牌位使用字符箭头作为图标，影响控制台页头；本轮不修改，建议另行选型。
该发现尚无持久任务票，请用户决定另建任务或不做；这里记录发现，不代表已排期。本次未穷举其他字符图标。
