# 模块权限设置 UI 原型

> 2026-09-09 防腐烂标记：下述原型保留早期设计，不能再作为现行权限语义依据。读写互不包含已由 ADR-0010 取代，当前写入包含读取；添加目录控件仍是未上线的设计。现行行为见 [模块权限](../../features/workflow-module-permissions.md)，实施约束见 [spec](../../specs/workflow-module-permissions.md)。复用该原型前必须先同步这两处差异并重新确认；本轮不修改页面或新增目录能力。

目标功能：模块首次启用和日常设置时，以模块卡片配置本地资源读写权限。

要回答的问题：用户能否清楚看出读取与写入互不包含、默认授权状态、文件执行始终禁止，以及权限不足不会在会话中临时申请。

原型是零后端设计验证。底部“演示状态”切换条和所有保存反馈都不会写入设置。

已确认的默认策略：所有已列出的资源都预选读取权限，写入权限均默认关闭；读取与写入互不包含。

模块卡片允许继续添加目录。新目录同样默认开启读取、关闭写入，随后可逐目录独立调整读写权限；原型中的“添加目录”只生成 mock 行，不调用系统目录选择器。
