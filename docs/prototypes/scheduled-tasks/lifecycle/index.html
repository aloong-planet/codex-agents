设计关注点

一次性提醒只有执行成功且推送完整被渠道接受才显示已完成，并从默认列表隐藏；这不等于手机已收到。待推送、失败与未知结果仍在默认列表，缓存和历史不删除。最新的停用会撤销此前手动执行的续发许可；停用后新发起的手动执行只允许发送自己的结果。迟到的失败不会盖掉已恢复的状态；重新绑定会清除旧会话，需要绑定后的新消息。缓存满时暂停生成，已有内容保留。该原型只演示单任务状态；跨任务排序、迁移、实际限额和时间计算须另行实现验证。
