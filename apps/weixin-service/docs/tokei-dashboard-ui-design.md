# Tokei 深色仪表盘页面设计

## 设计基准

用户提供的 Tokei 桌面悬浮面板截图是本次唯一视觉基准。此前基于 `XAMPPRocky/tokei` CLI 推导的终端表格风不符合目标，已经废弃。

本次只改页面视觉层和少量装饰性 HTML，不改五个 Tab、真实二维码、微信连接、权限、Memory Curator、日报、发送确认或任何业务状态机。

## 视觉语言

- 页面是一个深色、带柔和阴影和高圆角的悬浮应用窗口，而不是铺满浏览器的普通网页。
- 标题栏采用小型渐变圆环标记、产品标题、说明文字和右侧弱化状态，形成桌面工具感。
- 一级 Tab 放在半透明深灰胶囊内；当前项以浅色内嵌面、描边和字重共同标识。
- 功能区使用大圆角深色卡片。卡片背景和边框分别带珊瑚、蓝、紫灰和洋红的低饱和色偏，模拟截图中不同数据源卡片的分组方式。
- 数字、时间、原始 ID 和诊断使用等宽字体；中文说明和表单继续使用系统无衬线字体。
- 控件使用深色凹槽、柔和描边、12–16px 圆角；主动作使用蓝紫渐变，次动作使用中性深灰。
- 状态点、步骤号和小图标使用圆形 icon well 与微弱光晕，不复制 Tokei 标志或素材。
- 基础字号采用 15px，并压缩标题栏、Tab、卡片和表单间距，在保留触控面积的前提下维持截图中的紧凑仪表盘密度。

## 页面结构

### 应用壳

桌面端保留 16px 外边距，应用壳限制最大宽度并占据可视区高度；标题和 Tab 固定，只有 Tab 内容滚动。窄屏时壳体占满页面，去掉外边距和大部分外圆角。

### 微信连接页

- 当前状态是一条紧凑的深色摘要卡。
- 三个步骤在宽屏使用两列，第三张卡横跨整行；中窄屏改成单列。
- 三张卡分别使用珊瑚、蓝、洋红色偏，步骤号改为发光圆形徽标。
- 二维码始终位于纯白内衬中，不能套用深色滤镜。

### 其余 Tab

- 每个顶级功能页使用单张大卡片；聊天偏蓝、权限偏中性、Memory 偏洋红、新闻偏珊瑚。
- metadata、运行记录、消息和预览作为卡片内的次级深色槽位，不制造新的悬浮层级。
- Memory/Events 的二级 Tab 复用相同的胶囊分段样式。

## 交互与无障碍

- 保留现有 ARIA、键盘切换和 DOM ID。
- focus-visible 使用亮蓝双层轮廓；disabled 不只降低透明度，还保留明确文字和禁止光标。
- 成功、等待、失败继续使用绿、琥珀、红，并同时用边框与文字表达。
- 尊重 `prefers-reduced-motion`，不增加持续动画。
- 高对比模式加粗关键边界。

## 验收标准

- 第一眼呈现与截图相同的视觉家族：深色悬浮窗、圆角分段 Tab、双色微光卡片、圆形状态图标、紧凑仪表盘密度。
- 五个 Tab、表单、二维码、发送、权限、Memory 和新闻流程功能不变。
- 标题和 Tab 固定，内容区域独立滚动。
- 桌面、平板和手机宽度无页面级横向溢出；顶部 Tab 可独立横向滚动。
- 全量 lint、typecheck、单元/集成测试、build 和本地 E2E 通过。
